# 熊猫花花 AI 互动陪伴机器人 —— 调研与投资汇报材料

基于现象级熊猫 IP「花花」，打造**全球第一只 1:1 拟真、会眨眼、会动手脚、会对话、会成长的桌面陪伴熊猫**。

> 设计红线：整机 1:1 拟真熊猫，全身毛绒包覆，**零机械裸露**（绝不外露轮子/履带）；运动由内置舵机驱动肢体，行走为"能做则做"的选配。

## 目录结构

| 路径 | 说明 |
|---|---|
| `report/调研报告.md` | 完整调研报告：市场、7 款竞品优缺点对比、核心技术路线、系统架构、BOM 成本、安全合规、研发路线图、商业化与融资 |
| `dev/开发者技术路线与排期.md` | **面向开发者**：基于成熟开源项目（小智 xiaozhi-esp32 / Will Cogley 仿生眼 / PCA9685）的改造方案、物料清单、按"下班+周末"时间的分周排期、投资人 Demo 脚本 |

1. 封面 · 熊猫花花

4. 主流竞品横向对比表（新增"拟真外形"维度）

6. 产品定位与五大护城河（拟真外形排第一）

8. **内部结构爆炸示意图（机构全部藏在毛绒下）**
9. 技术 2/4：可动头部与四肢（12–16 自由度）
10. 技术 3/4：端云协同大模型对话

15. 15 个月研发路线图
16. 商业化与融资规划
17. 结尾愿景
