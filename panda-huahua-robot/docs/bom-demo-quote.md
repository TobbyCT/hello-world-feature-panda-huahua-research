## 1. 报价结论

本期不是量产 BOM，而是“能拿给投资人看的初期 Demo 样机预算”。

建议对投资人采用以下口径：

| 口径 | 建议金额 | 适用说明 |
|---|---:|---|
| 纯物料采购成本 | 约 1,500 - 5,500 元 | 只含电子、舵机、玩偶、打印件和杂项，不含人工调试 |
| 自研自装 Demo 成本 | 约 5,000 - 10,000 元 | 你自己装配调试，只外包少量 3D 打印 / 缝制 |
| 可对外展示样机报价 | 建议 20,000 - 30,000 元 | 含结构改造、装配、动作标定、语音、演示脚本、返工余量 |
| 更稳妥的投资人预算 | 建议写 30,000 元 / 台 | 适合放进融资计划，包含 15%-25% 风险余量 |

一句话建议：

> 投资人沟通中建议说“首台 Demo 样机预算约 3 万元，不含 IP 授权、量产开模和认证费用；其中硬件物料约 3,000-5,000 元，主要成本在结构改造、动作调试、返工和演示稳定性。”

## 2. BOM 假设

| 项目 | 假设 |
|---|---|
| 样机尺寸 | 桌面级 / 中小型展台样机，约 45-60cm 毛绒熊猫 |
| 动作范围 | 眼部 6 舵机、头部 2 舵机、前肢 1-2 舵机 |
| 下肢 | 不动 |
| 触摸 | 只做头部触摸 |
| 语音 | 预置语音播放为主，小智大模型对话作为增强 |
| 供电 | Demo 阶段优先外接 USB / DC 电源，不先做电池 |
| 外观 | 现成熊猫毛绒玩具改造，不做定制量产外皮 |
| 生产方式 | 单台手工样机，不按量产采购价计算 |

## 6. 可选升级项

| 升级项 | 费用区间 | 何时需要 |
|---|---:|---|
| 电池供电 + 充电管理 | 200 - 800 | 需要无电源线展示时 |
| 摄像头 / 人脸方向感知 | 100 - 500 | 需要“看向人”的视觉能力 |
| 总线舵机升级 | 500 - 2,000 | 需要位置反馈、减少线束、提高稳定性 |
| 定制毛绒外皮 | 2,000 - 10,000+ | 需要更接近花花比例与商业展示质感 |
| 专属音色 / TTS 定制 | 500 - 5,000+ | 需要品牌化声音 |
| 小智自建后端 | 0 - 3,000 | 需要可控人设、记忆和私有部署 |

## 9. 报价备注

1. 单台 Demo 样机价格不等于量产 BOM，首台样机一定会有返工和调试成本。
2. 投资人预算建议按“项目打样成本”表达，不建议只展示“物料成本”，否则会低估真实投入。
3. 当前价格为 2026-06-10 前期估算，实际采购需按淘宝、1688、立创商城、嘉立创 3D 打印或本地供应商实时报价复核。
4. 如果预算紧张，优先保留：眼部眨眼、头部点头、摸头回应、预置语音、右前肢挥手。
5. 如果预算增加，优先升级：眼部静音、头部支架强度、毛绒外观复原、演示视频质量。
