# 熊猫花花 · 开发者技术路线与排期（投资人 Demo 优先版）

> 读者：你（独立开发者）｜ 目标：**用最少的自研，在成熟开源项目上改造，尽快做出能给投资人演示的样机**
> 时间约束：工作日 19:30 到家 → 有效开发 ~2h/晚；周末双休 → ~5h/天。预算约 **18 小时/周**。
> 核心策略：**改造现成的，而不是从零开发**；**Demo 优先**（先做出"会说话+会眨眼+会招手的真熊猫"），视觉/行走等后置。

---

## 0. 一句话技术选型

> **买一只大号熊猫毛绒玩具做外壳 → 塞进【小智 xiaozhi-esp32】当对话大脑 → 用【PCA9685 + 舵机】驱动【Will Cogley 开源仿生眼】和头/手 → 用小智的 MCP 让大模型触发动作。**

这条路线 90% 是"组装 + 改配置 + 写少量动作脚本"，不需要自研语音链路、不需要自研大模型对接、不需要自研眼球机构。

---

## 1. 推荐复用的成熟开源/现成方案

|---|---|---|---|

| **舵机驱动** | [Adafruit PCA9685 库](https://github.com/adafruit/Adafruit-PWM-Servo-Driver-Library) + PCA9685 16 路板 | I2C 一根线驱动 16 路舵机，库成熟，Arduino/ESP32 通用 | 接线 + 写动作关键帧 |
| **眼睛动画算法** | Cogley 控制器自带的随机扫视/眨眼；或 [arduino-animatronic-eyes](https://github.com/Robin-Sch/arduino-animatronic-eyes) | 现成的"自然眨眼/扫视"逻辑 | 加"说话时眨眼频率↑""听人说话时看向声源"的简单状态机 |
| **外壳** | **买现成的大号熊猫/花花毛绒玩具**改造 | 省掉最难的拟真外形与缝制，直接满足"1:1 像真熊猫、零机械裸露" | 开背部隐藏拉链 → 掏空 → 装内骨骼/眼/舵机 → 复原 |

## 2. 样机系统架构（最省力版）

```
            ┌─────────── 云/自建服务端 ───────────┐
            │  LLM(DeepSeek/豆包/Qwen) + ASR + TTS │
            │  花花人设 Prompt + 简易成长状态        │
            └───────────────▲─────────────────────┘
                            │ Wi-Fi (小智协议/MCP)
        ┌──────────── ESP32-S3 (小智固件) ─────────┐
        │  唤醒词"花花" · 录音/播放 · 对话           │
        │  MCP 工具: wave() blink() nod() sit() ... │
        └──────────────▲─────────────┬─────────────┘
                麦克风/扬声器          │ I2C
                              ┌───────▼────────┐
                              │  PCA9685 16路   │
                              └──┬───────────┬──┘
                  ┌──────────────┘           └───────────────┐
            仿生眼6舵机(Cogley)            头2 + 前肢2~4 + 腰1 舵机
                 (藏于头部)                    (藏于身体内骨骼)
        ──────────────────────────────────────────────────────
              全部封装进【现成熊猫毛绒玩具】外壳内，背部隐藏拉链维修口
```

要点：**小智 ESP32 负责"听说想"，PCA9685+舵机负责"动"**，两者在同一块 ESP32 上用 MCP 工具回调打通——大模型说"我跟你招招手"时，调用 `wave()` 让前肢舵机动。这就是"自主完成动作"的最小实现。

## 4. 分阶段排期（按 18h/周；含两条路线）

### 路线 A —— "极速 Demo"（3 周，约 50h）：会说话 + 会眨眼 + 会招手的真熊猫
> 目标：能上桌给投资人演示的最小可信样机（MVP）。

| 周 | 时段 | 任务 | 完成标准(DoD) |
|---|---|---|---|
| **第0周(下单)** | 任意晚 1h | 按 §3 下单所有物料 + 提交仿生眼 STL 代打印 | 物料在途；打印件已下单(打印 3–5 天) |
| **W1·工作日晚(4×2h)** | 晚 | 刷 **小智 xiaozhi-esp32** 固件跑通对话；接 DeepSeek/豆包 Key；改唤醒词与"花花"人设 Prompt | 对着板子喊"花花"，它用花花口吻语音回答 |
| **W1·周末(2×5h)** | 周末 | 组装 **Cogley 仿生眼**(6 舵机+PCA9685)；跑通眨眼/扫视示例 | 眼睛能自动眨眼、左右看，眼皮能开合 |
| **W2·工作日晚** | 晚 | 在小智里用 **MCP 注册动作工具** `blink/look/wave/nod`；把舵机控制接进去 | 在对话里说"眨个眼/招手"，眼或手真的动 |
| **W2·周末** | 周末 | 装 **头(2)+前肢(2)** 舵机；写"招手/点头/侧头"关键帧动作 | 招手、点头动作流畅，无异响 |
| **W3·工作日晚** | 晚 | **情绪↔动作映射**：说话时眨眼↑、开心时招手、被叫名字时看向人 | 对话与动作联动自然 |
| **W3·周末** | 周末 | 掏空熊猫玩偶、装内骨骼/眼/舵机、背部留隐藏拉链；**整机封装(零裸露)** + 录演示视频 | 一只"会说会眨会招手"的真熊猫，外观看不到任何机械 |

✅ **W3 末交付物**：可现场演示的样机 + 2 分钟演示视频 + 话术脚本（§6）。**这一版足够打动早期投资人。**

### 路线 B —— "完整 Demo"（再加 3–4 周，约 60–70h）：加养成系统 + 更多动作 + 视觉(可选)
| 周 | 任务 | 完成标准 |
|---|---|---|
| **W4** | 自建 **xiaozhi-esp32-server**，掌控人设/记忆；加简易"成长状态"(亲密度/心情存数据库) | 多轮对话能记住名字/偏好；亲密度随互动上涨 |
| **W5** | 扩充动作库(作揖/坐起/趴下/扭身/耳朵抖)；加腰部舵机 | ≥8 个可触发动作 |
| **W6** | 做一个极简 **成长看板**(手机网页/小程序)：显示心情、亲密度、成长阶段 | 演示"互动→成长"闭环 |
| **W7(选配)** | 加摄像头做人脸识别/看向人；或评估行走可行性(做不到就砍) | 能"认出主人并转头看"；行走结论明确 |

> **行走**按上一轮结论：**能做则做、做不到就放弃，不影响核心体验**——放在最后评估，绝不阻塞 Demo。

## 5. 关键技术风险与应对（独立开发者视角）

| 风险 | 应对 |
|---|---|
| 仿生眼塞不进熊猫头/太大 | 选玩偶时挑头部够大的(≥18cm)；或用 Cogley 的紧凑版/缩放打印 |
| 舵机噪音破坏"生命感" | 眼用静音微型舵机；动作加缓动(ease-in/out)；演示环境别太安静 |
| ESP32 算力/动作实时性不够 | 动作用关键帧预存，ESP32 只做插值；复杂逻辑放服务端 |
| 现场网络不稳定导致对话失败 | **准备热点 + 预录兜底**；保留 **Wizard-of-Oz**（手机偷偷遥控触发动作/播放）作为终极保险 |
| 大模型说错话/越界 | 人设 Prompt 加边界；演示走"预设问题"路径 |
| 开源件商用授权 | Demo 自用 OK；**量产前逐一核对 LICENSE 与作者授权** |

## 6. 投资人演示脚本（2–3 分钟）

1. 走近喊"**花花**" → 它**睁大眼睛看向你**并打招呼（展示唤醒+仿生眼对视）。
2. 问"花花你今天开心吗？" → 它**眨眨眼、侧头**用花花口吻回答（展示对话+情绪眼神）。
3. 说"跟叔叔阿姨**招招手**" → 它**抬起前肢挥手**（展示对话触发动作 = MCP）。
4. 摸摸头/夸它 → 屏幕/语音显示**亲密度+1**（展示成长系统，路线B）。
5. 收尾一句话："**它长得就是一只真熊猫，但会眨眼、会聊天、会跟你一起长大**" → 强调零机械裸露的差异化。

> 演示三件套：① 样机；② 2 分钟视频(防现场翻车)；③ 一页"技术已跑通"清单(小智/Cogley/MCP 截图)。

## 8. 动作代码骨架 + 舵机裸测 Demo（已给你写好，直接套用）

`dev/` 下已提供两套代码，省去你从零写：

**A) 动作骨架 `dev/xiaozhi-mcp/`**（裸测与正式固件共用）
| 文件 | 作用 | 谁编译 |
|---|---|---|
| `panda_servos.h/.cc` | PCA9685 驱动 + 关节通道映射 + 安全限位 + ease 缓动 | Demo + 固件 |
| `panda_actions.h/.cc` | 动作引擎(`Enqueue` 异步 / `RunBlocking` 同步) + 关键帧动画 | Demo + 固件 |
| `panda_mcp_tools.h/.cc` | `RegisterPandaTools()` 把动作注册成 `self.panda.wave/blink/nod/...` | **仅固件** |

**B) 舵机裸测 Demo `dev/panda-servo-demo/`**（拿到舵机当晚就能跑）
- 完整 ESP-IDF 工程，不接大模型/不连 Wi-Fi，串口 REPL 直接敲 `blink/nod/wave/look/sit/happy`，
  还带 `cal/sweep/list` 标定命令和 `idle on` 待机生命感。
- 调通后 `panda_servos.* + panda_actions.*` 原样进固件，再加 `panda_mcp_tools.*` 即可让大模型触发同一套动作。

要点：**MCP 回调只入队、立即返回**（动作在独立任务播放，不卡对话）；关节角度/I2C 引脚/舵机脉宽按实物标定。
**W2「对话→动作」**正是：先用 Demo 把动作和标定搞定 → 再把三组文件接进小智固件。
